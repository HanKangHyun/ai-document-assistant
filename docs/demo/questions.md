# 공개용 샘플 PDF 시연 질문과 정답표

## 사용 방법

1. `aurora-service-demo.pdf`만 문서 도우미에 업로드합니다.
2. 새 문서를 선택하고 **의미 검색 준비**를 눌러 완료를 기다립니다.
3. 아래 질문을 **문서에 질문하기**에 하나씩 입력합니다.
4. 답변 내용과 출처 페이지를 비교합니다. 이 정답표는 업로드하지 않습니다.

이 자료의 서비스·일정·성과 수치는 전부 가상입니다. 샘플 속 구현 범위를 실제 AI Document Assistant의 기능이나 본인 경력으로 소개하지 않습니다. 기대 답변은 원문 기준이며 실제 모델 응답을 미리 보장하는 결과가 아닙니다.

## 먼저 찍을 시연 화면 3장

| 순서 | 질문 또는 화면 | 보여줄 내용 |
|---|---|---|
| 1 | PDF 업로드 후 의미 검색 준비 완료 | 문서 제목, 5페이지, 검색 준비 상태 |
| 2 | 사람이 반복하던 작업을 줄인 사례를 설명해 주세요. | 배포 자동화 사례와 2페이지 출처 |
| 3 | 담당 개발자의 희망 연봉은 얼마인가요? | 문서에 없는 금액을 지어내지 않고 답변 보류 |

영상에서는 2번 답변의 PDF 출처 링크를 눌러 실제 원문도 보여주세요. 화면 캡처 전에 다른 개인 문서의 제목이 왼쪽 목록에 보이지 않도록 결과 영역만 캡처하거나 가상 문서만 있는 별도 시연 환경을 사용하세요.

## 평가 기록 방법

각 질문에 대해 아래 내용을 기록합니다. 정답표가 보여주는 페이지와 화면의 sourceId는 다른 개념입니다. `[1]`은 첫 번째 출처 ID일 뿐 1페이지라는 뜻이 아니므로 PDF 페이지를 확인하세요.

| 항목 | 기록 기준 |
|---|---|
| 답변 상태 | 생성 / 원문만 / 답변 보류 / 오류 |
| 사실 일치 | 기대 핵심 내용과 일치하는지, 없는 내용을 추가했는지 |
| 출처 | 실제 근거 페이지를 인용했는지 |
| 응답 시간 | 질문 클릭부터 답변 표시까지 초 단위로 측정 |
| 메모 | 누락, 추측, 역할 혼동, 가상 수치를 실제 성과로 설명한 경우 등 |

질문 01~15의 답변 품질과 16~20의 답변 보류 결과를 분리해서 기록하세요. 최초 모델 로딩과 후속 응답의 시간을 구분하고, 실패 사례도 포함하세요. 아직 이 샘플로 실제 모델 평가를 실행한 것은 아니므로 정답률·평균 지연 시간은 빈 값으로 두세요.
